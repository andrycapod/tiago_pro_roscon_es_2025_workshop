## TIAGo PRO Navigation and HRI Workshop — ROSCon @ ES 2025

Bienvenido al repositorio oficial del workshop “TIAGo PRO Navigation and HRI”, presentado durante la ROSCon @ ES 2025.
Este workshop está diseñado para mostrar las capacidades avanzadas del robot TIAGo PRO, así como los frameworks de navegación y de interacción humano-robot (HRI) desarrollados por PAL Robotics.

Al final del workshop, los participantes crearán una aplicación práctica de “Follow Me”, donde el robot combinará sus capacidades de navegación autónoma y detección/interacción humana.


### 🎯 Objetivos del Workshop

En este workshop aprenderás a:

- Explorar las capacidades del robot TIAGo PRO en escenarios reales.
- Comprender y utilizar el stack de navegación basado en Nav2 y Behavior Trees.
- Usar las APIs de HRI de PAL Robotics para detectar y seguir a personas en el entorno.
- Integrar navegación y HRI en una aplicación completa de “Follow Me”, donde el robot detecta, sigue y mantiene interacción con un humano

### 🚀 Cómo Empezar

Clona este repositorio:

```bash
git clone https://github.com/pal-robotics/roscon-es-2025-workshop-tiago-pro.git
cd roscon-es-2025-workshop-tiago-pro
```

Sigue el ejercicio 0 para preparar el entorno Docker.
Completa los ejercicios siguientes en orden para desarrollar la aplicación final de Follow Me.
